# 🐟 ระบบบริหารการจองพันธุ์ปลาและคิวจัดส่ง - ฟาร์มปลาผู้ใหญ่พร

ระบบเว็บแอปพลิเคชันสำหรับบริหารจัดการการจองพันธุ์ปลา คิวจัดส่ง/รับหน้าฟาร์ม การแจ้งเคลมสินค้าพร้อมหลักฐานภาพถ่าย และประวัติลูกค้าตลอดชีพ ออกแบบมาเพื่อรองรับการใช้งานผ่านคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน (Mobile Friendly) ด้วยดีไซน์ปุ่มขนาดใหญ่ สีขาว-เหลือง-ฟ้า ใช้งานง่ายและทันสมัย

---

## 🚀 วิธีการเปิดใช้งานระบบ

คุณสามารถเปิดใช้งานระบบได้ 2 รูปแบบตามความสะดวก:

### รูปแบบที่ 1: เปิดใช้งานได้ทันที (ไม่ต้องติดตั้งโปรแกรมใดๆ)
1. เข้าไปที่โฟลเดอร์ `จองปลา` บนหน้า Desktop ของคุณ
2. **ดับเบิ้ลคลิกที่ไฟล์ `index.html`**
3. ระบบจะเปิดขึ้นมาบนเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, Safari ฯลฯ) และพร้อมใช้งานได้ทันที 100% พร้อมข้อมูลตัวอย่างครบถ้วน

---

### รูปแบบที่ 2: รันเป็นเซิร์ฟเวอร์ออนไลน์ / เครือข่าย (สำหรับหลายคนใช้งานพร้อมกัน)
หากต้องการให้ทีมงาน คนขับรถหน้างาน หรือผู้จัดการเปิดใช้งานผ่านมือถือจากที่ไหนก็ได้:
1. เปิด Terminal / PowerShell ที่โฟลเดอร์นี้
2. ติดตั้งแพ็กเกจ (ทำครั้งแรกครั้งเดียว):
   ```bash
   npm install
   ```
3. เริ่มต้นรันเซิร์ฟเวอร์:
   ```bash
   npm start
   ```
4. ระบบจะทำงานที่:
   * บนเครื่องหลัก: `http://localhost:3000`
   * บนมือถือหรือเครื่องอื่นๆ ในวง Wi-Fi: `http://<IP-เครื่องหลัก>:3000`

## ✨ ฟีเจอร์หลักของระบบ

### 1. ระบบบันทึกการจองพันธุ์ปลาและสินค้า (Booking)
* บันทึกข้อมูลลูกค้า: ชื่อ, เบอร์โทรศัพท์ (แตะโทรออกได้), ที่อยู่จัดส่ง, ลิงก์ Google Maps นำทาง
* ตัวเลือกลักษณะการรับสินค้า: **"🚚 จัดส่งถึงที่"** หรือ **"🏠 มารับเองที่หน้าฟาร์ม"**
* เพิ่มรายการสินค้าได้ไม่จำกัด:
  * **พันธุ์ปลา:** ปลาดุกบิ๊กอุย, ปลานิลจิตรลดา, ปลาทับทิม, ปลาสวาย, ปลากดคัง, ปลาสลิด, ปลาหมอ ฯลฯ พร้อมขนาด/ไซส์ และจำนวน
  * **อาหารปลา:** ไฮเกรด 9006T, อาหารปลาดุกเล็ก/ใหญ่, อาหารปลากินพืช (กระสอบ)
  * **กระชังเลี้ยงปลา:** กระชังบก, กระชังน้ำมุ้งเขียว หลากหลายขนาด
  * **ยารักษาโรคปลา / วิตามิน / ด่างทับทิม / เกลือ**
* **ระบบส่วนลดต่อหน่วยสินค้า (บาท/หน่วย โดยตรง ไม่มี %):** คำนวณราคาสุทธิ x จำนวนให้อัตโนมัติ
* ระบบคำนวณเงินมัดจำ และยอดคงเหลือที่ต้องเก็บวันส่ง

### 2. ระบบแก้ไขข้อมูลการจอง & บันทึกประวัติผู้แก้ไขและเหตุผล (Audit Trail)
* สามารถกดปุ่ม **"✏️ แก้ไขการจอง"** เพื่อเปลี่ยนแปลงข้อมูลได้ทั้งหมด:
  * เปลี่ยนวันนัดจัดส่ง / วันนัดรับสินค้า
  * เปลี่ยนแปลงรายการสินค้า เพิ่ม/ลดชนิดปลา ไซส์ จำนวน และส่วนลดต่อหน่วย
  * ปรับเปลี่ยนเงินมัดจำ และสถานที่จัดส่ง
* **บันทึกประวัติการแก้ไขอัตโนมัติ:**
  * ระบุชื่อและบทบาทของผู้ทำการแก้ไข (เช่น คุณสมศักดิ์ ผู้จัดการฟาร์ม)
  * **บังคับระบุ "เหตุผลในการแก้ไข"** เช่น ลูกค้าขอเลื่อนวันส่งเพราะน้ำไม่พร้อม หรือ ปรับเพิ่มจำนวนปลา
  * บันทึกวัน-เวลา และสรุปรายการที่เปลี่ยนแปลงอย่างโปร่งใส
* ปุ่ม **"📝 ประวัติแก้ไข"** สำหรับเปิดดูไทม์ไลน์การเปลี่ยนแปลงย้อนหลังทั้งหมดของออเดอร์นั้นได้ตลอดเวลา

### 3. ปฏิทินคิวงานทั้งเดือน (Monthly Calendar View)
* ดูภาพรวมงานทั้งเดือน เช็คได้ทันทีว่า **วันไหนคิวว่าง** หรือวันไหนมีคิวกี่เจ้า
* แยกสีสัญลักษณ์ชัดเจน: สีฟ้า (จัดส่ง) และ สีเหลือง (รับเองหน้าฟาร์ม)
* คลิกเลือกดูรายละเอียดคิวงานในแต่ละวันได้ทันที

### 3. คิวจัดส่งประจำวัน & สรุปปลาขึ้นรถ (Daily Queue & Driver View)
* **กล่องสรุปสินค้าที่ต้องเตรียมขึ้นรถประจำวัน:** รวบรวมยอดปลาและสินค้าทุกออเดอร์ในวันนั้น เช่น วันนี้ต้องตักปลาดุกรวมกี่หมื่นตัว ปลานิลกี่ตัว อาหารกี่กระสอบ
* หน้าจอคนขับรถ: ปุ่มกดโทรหาลูกค้า, ปุ่มเปิด Google Maps นำทาง, ปุ่มอัปเดตสถานะการจัดส่ง
* บันทึกการรับเงินสด / สแกนโอน พร้อมช่องแนบภาพสลิปโอนเงิน

### 4. ระบบแจ้งเคลมสินค้า & ภาพถ่ายยืนยันความเสียหาย (Claims & Photos)
* บันทึกรายการปลาที่ตาย/น็อคน้ำหน้างาน หรือสินค้าชำรุด
* **ช่องเพิ่มภาพถ่ายยืนยันความเสียหาย:** ถ่ายภาพจากกล้องมือถือหน้างาน หรือแนบไฟล์รูปภาพ พร้อมระบบกดขยายดูรูปขนาดใหญ่
* ระบุแนวทางชดเชย: หักลดยอดจ่ายหน้างานทันที / ส่งปลาชดเชยรอบหน้า / โอนเงินคืนลูกค้า
* ระบบให้ฝ่าย QC ตรวจสอบและกดอนุมัติการเคลม

### 5. ใบจอง / ใบส่งมอบสินค้า & แชร์เข้า LINE
* ออกใบจอง/ใบเสร็จ/ใบส่งของ จัดหน้าสวยงามพร้อมพิมพ์ลงกระดาษหรือบันทึกเป็น PDF
* ปุ่ม **"📲 ส่งข้อความเข้า LINE"** สร้างข้อความสรุปพร้อมอีโมจิสวยงาม นำไปวางส่งให้ลูกค้าในแชท LINE ได้ในคลิกเดียว

### 6. ประวัติลูกค้าตลอดชีพ & จัดเกรด VIP (Customer CRM)
* ค้นหาประวัติลูกค้าย้อนหลังได้แบบไม่จำกัดระยะเวลา
* สรุปยอดซื้อสะสมปีปัจจุบัน และยอดซื้อสะสมตลอดชีพ (Customer Lifetime Value)
* จัดเกรดลูกค้าอัตโนมัติ: **🌟 VIP**, **🥈 ลูกค้าประจำ**, **🥉 ลูกค้าทั่วไป** เพื่อมอบโปรโมชั่นและส่วนลดพิเศษ

### 7. แดชบอร์ดสรุปสถิติฟาร์ม & ส่งออก Excel (Analytics)
* ดูยอดขายรวมปีนี้, ยอดมัดจำ, จำนวนออเดอร์, และมูลค่าการเคลม
* อันดับพันธุ์ปลาและสินค้าขายดี 5 อันดับแรก
* อันดับลูกค้าที่มียอดซื้อสูงสุดประจำปี
* **ปุ่มส่งออกข้อมูลเป็นไฟล์ Excel (.xlsx):**
  * ส่งออกคำสั่งจองทั้งหมด
  * ส่งออกรายชื่อลูกค้าและยอดสะสม
  * ส่งออกรายงานภาพรวมประจำปี
